# Sherpa — проводник по квестам Escape from Tarkov

Sherpa помогает пройти квесты быстрее: показывает, **куда идти, в каком порядке, что взять с собой и за сколько продать лут**.
Отмечаешь активные квесты (свои и тиммейтов) — приложение разбивает цели на рейды, строит реальные маршруты по карте
и ведёт тебя в рейде, как навигатор.

Приложение для Windows (Electron, безрамочное окно) — работает без настроек браузера и в любой системе, где есть Windows.
Веб-версия тоже осталась (Chrome/Edge). Данные — с [tarkov.dev](https://tarkov.dev), интерфейс в стиле Таркова.

## Возможности

### 🗺 Карты и квесты
- **Все 13 локаций**: Улицы Таркова, Эпицентр, Таможня, Завод, Ледокол, Развязка, Лаборатория, Лабиринт, Маяк, Резерв,
  Берег, Терминал, Лес — с переключением этажей и подписями районов на русском.
- **500+ квестов PvP и PvE** на русском: цели, зоны на карте, все места появления квестовых предметов, нужные ключи,
  иконки предметов, картинки квестов, ссылки на вики.
- Фильтры «Активные / Доступные / Все»: доступные учитывают уровень и выполненные предыдущие квесты.
- Невзятые квесты карты можно показать серыми точками и взять прямо с карты.

### 🧭 Планирование рейдов
- **Рейды по районам**: цели карты автоматически делятся на несколько рейдов, каждый укладывается в реалистичное время.
  Рейд получает название по районам («Аптека 1 · LexOs»), вероятный спавн и ближайший выход.
- **Реальные пути**: маршрут идёт по улицам и проходам, в обход зданий, заборов, воды, скал и минных полей.
  Порядок точек и время пересчитываются по настоящей длине пути.
- **Пути внутри зданий**: клик по цели строит подробный маршрут через дверные проёмы и лестницы, карта сама
  переключается на нужный этаж, на ней отмечены «ВХОД» и «▲ 2 этаж». Под целью — подсказка:
  «вход в здание → ▲ подняться на 2 этаж → цель».
- Настройки темпа: скорость, какую долю рейда планировать, учитывать ли зоны убийств. Выход можно выбрать вручную.
- Квесты без точек на карте (убийства, выживание) показываются отдельно — «попутно в любом рейде».

### 🎯 Навигатор в рейде
- **Твоя позиция и направление взгляда** по скриншотам игры: нажал клавишу скриншота — увидел себя на карте.
  Подходит любая клавиша: приложение следит за новыми файлами, а не за клавиатурой (назначенная клавиша читается из настроек игры для подсказок).
- **HUD**: стрелка к следующей цели, дистанция по пути, подсказка «▲ наверх: 2 этаж · через 12 м», «выше на 2 эт.»,
  мини-радар, таймер рейда и отставание от плана, кнопки «Выполнено / Пропустить».
- У цели навигатор ведёт через двери и лестницы, а не напрямик сквозь стены.
- **Прозрачный виджет поверх игры** со стрелкой, миникартой (колесо — масштаб), целью и кнопками. Сам открывается, когда
  начинается рейд, и предлагает маршрут. Двигается, меняет размер, прозрачность и масштаб, умеет пропускать клики в игру.
  Горячие клавиши: `Ctrl+Shift+N` показать/скрыть, `Ctrl+Shift+L` клики сквозь виджет, `Ctrl+Shift+D` выполнено,
  `Ctrl+Shift+S` пропустить. Нужен режим игры «Оконный без рамки».
- **Карта и PvP/PvE определяются сами** по логам игры, начало рейда засекается автоматически.
- **Маршрут от точки спавна**: первый скриншот в рейде — точка спавна; первым идёт рейд «От спавна», остальные
  квесты раскладываются на следующие рейды. Если перед скриншотом дважды нажать O, Sherpa прочитает с картинки
  открытые тебе выходы и поведёт только к ним.

### ✅ Прогресс квестов
- **Из логов игры**: «задание получено / выполнено / провалено» отмечается автоматически; кнопка «Загрузить прогресс
  из всех логов» восстанавливает всю историю.
- **Со скриншота списка заданий**: распознавание текста находит активные квесты; все квесты, без которых они бы
  не открылись, отмечаются выполненными.
- Ручные отметки: статус квеста у каждого игрока и галочки по отдельным целям.
- Сохранение прогресса в файл и загрузка из файла.

### 👥 Группа
- Игроки «Игрок 1, Игрок 2, Игрок 3…» — добавляй, переименовывай, задавай цвет и уровень.
- Общие цели нескольких игроков сливаются в одну точку маршрута и помечаются на карте.
- Отметка «это я» — к этому игроку применяются логи и скриншоты с твоего компьютера.

### 💰 Барахолка и снаряжение
- **Что взять в рейд**: ключи, маркеры, предметы для закладки; что найти на карте; что сдать торговцам (с пометкой FIR).
- **Цена при наведении** на любую иконку предмета: минимальная на барахолке, средняя за сутки, тренд за 48 ч,
  число лотов, лучший торговец, цена за клетку.
- **Рекомендуемая цена продажи** с учётом спроса и комиссии барахолки по формуле игры; если выгоднее торговец — скажет.
  Учитывается скидка разведцентра 3 уровня.
- **Мой лут**: список предметов с итоговой стоимостью, сортировка по цене за клетку; распознавание инвентаря
  со скриншота (бета).
- Обновление цен с tarkov.dev одной кнопкой.
- **Цена прямо в игре** (как в Blitz): наводишь курсор на предмет в схроне или в рейде — под подсказкой игры появляется
  карточка: барахолка, лучший торговец, цена за клетку, что выгоднее и для каких активных квестов он нужен.
  Работает с русской и английской версией игры, сама при наведении или по `Ctrl+Shift+P`.

### 🖥 Приложение
- Значок в скрытых значках у часов: крестик сворачивает в трей, Sherpa продолжает ловить рейды и цены.
- Установщик спрашивает, куда ставить (можно не на диск C).
- **Обновление по кнопке**: скачиваются только изменившиеся части, ставится в ту же папку, прогресс сохраняется.

## Установка

Скачай `Sherpa-Setup-<версия>.exe` со страницы [Releases](https://github.com/Flitering/Sherpa/releases/latest), запусти и
выбери папку. Windows может предупредить о неизвестном издателе (у приложения нет платной подписи) —
«Подробнее» → «Выполнить в любом случае». Дальше обновления приходят кнопкой в самом приложении.

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 20+.

```bash
npm install
npm run sync          # скачать квесты, цены и карты в public/ (встраиваются в сборку)
npm run desktop:dev   # приложение с горячей перезагрузкой интерфейса
npm run dist          # установщик в release/
```

`npm run desktop` — собрать и запустить без установщика; `npm run dev` — веб-версия на http://127.0.0.1:5173;
`npm run sync -- pve` — обновить только PvE.

В установленном приложении данные обновляются кнопкой «Обновить данные» на вкладке «Навигатор» — свежая копия
кладётся в `%APPDATA%\Sherpa\content` и подменяет встроенную.

## Как пользоваться

При первом запуске откроется **мастер настройки** (потом — кнопка «⚙ Настройка» вверху). Он по шагам проведёт:

1. **Группа и режим** — имена игроков, уровни, кто из них «я», PvP или PvE.
2. **Скриншоты** — папка `Документы\Escape from Tarkov\Screenshots` (приложение находит её само, в том числе в OneDrive).
   Само оно экран не снимает: когда ты в рейде жмёшь клавишу скриншота (любую, какую назначил в игре), игра пишет
   координаты в имя файла, Sherpa читает только имя.
3. **Логи игры** — папка `Logs` находится сама по месту установки (лаунчер BSG или Steam), иначе её можно выбрать.
   Из логов Sherpa узнаёт карту, начало и конец рейда, режим и взятые/сданные квесты (кнопка «Загрузить прогресс из всех логов»).
4. **Виджет поверх игры** — режим игры «Оконный без рамки», автозапуск виджета и горячие клавиши.

Индикаторы «Скриншоты» и «Логи» в шапке показывают, всё ли подключено. В веб-версии браузер после перезапуска может
снова спросить разрешение — жёлтый индикатор, нажми на него.

**В рейде всё происходит само:** как только ты зашёл в рейд, поверх игры появится виджет с выбором маршрута — одно
нажатие, и он превращается в навигатор. Виджет двигается за верхнюю полосу, меняет размер за края, сворачивается в
компактный вид. Когда выходишь из рейда, навигатор закрывается и показывает, сколько целей выполнено.

Дальше по вкладкам:
- **Квесты** — статусы квестов; у каждой цели номер точки маршрута («2.3» — рейд 2, точка 3), как на карте.
- **Рейды** — выходы этого рейда, маршруты по районам, клик по цели — подробный путь через двери и лестницы.
- **Снаряжение**, **Барахолка**, **Навигатор**, **Группа**.

Скриншоты приложение не удаляет — чисти папку сам.

## Безопасность и блокировки

Приложение **не взаимодействует с процессом игры**: не читает память, не внедряется в игру, не рисует поверх неё,
не нажимает клавиши и не изменяет файлы игры. Оно только читает то, что игра сама пишет на диск: имена скриншотов,
логи и (для подсказки) файл настроек управления.

| Функция | Как работает | Риск |
|---|---|---|
| Данные квестов, карт, цен | публичные данные tarkov.dev | нет |
| Позиция по скриншоту | игра пишет координаты в имя файла скриншота, приложение читает имя; клавишу нажимает сам игрок | очень низкий — так же работают Tarkov Pilot и TarkovMonitor |
| Карта, режим, квесты по логам | чтение текстовых логов игры | очень низкий — так же делает TarkovMonitor |
| Распознавание скриншотов | снимок экрана через браузер (с твоего разрешения) или файл | нет |
| Виджет поверх игры | обычное прозрачное окно Windows «поверх всех окон», в игру не встраивается | нет |
| Цена по наведению | кадр экрана берётся тем же способом, что у OBS и Discord; положение курсора опрашивается, мышь не перехватывается | очень низкий — так же работают RatScanner и Blitz |
| Горячие клавиши виджета | обычные глобальные сочетания Windows, нажатия в игру не посылаются | нет |

**Чего приложение не делает и делать не будет**: чтение памяти игры, внедрение в процесс или DirectX-оверлей,
эмуляция ввода (в том числе автонажатие клавиши скриншота). Файлы читаются только из папок скриншотов и логов.

Защита приложения описана в [SECURITY.md](SECURITY.md). Зависимости закреплены по версиям. `npm audit` находит только предупреждения средней важности в инструментах сборки
(electron-builder), в само приложение они не попадают. Dev-сервер слушает только `127.0.0.1`.

## Устройство

| Файл | Что делает |
|---|---|
| `electron/main.mjs` | Окна (главное и прозрачный виджет), протокол `app://`, поиск папок игры, чтение файлов, горячие клавиши, обновление данных |
| `electron/preload.cjs`, `src/lib/desktop.ts` | Мост между окном и системой; «папки» поверх файловой системы для кода навигатора |
| `electron/pricecheck.mjs`, `src/price/` | Цена по наведению: курсор, захват экрана, поиск подсказки игры, распознавание названия; `src/price/iconscan.ts` — распознавание по картинке в клетке (как RatScanner, но при наведении) |
| `electron/stylemaps.mjs`, `src/lib/styledMaps.ts` | Перекраска растровых карт (Лаборатория, Лабиринт, Ледокол) в стиль схем tarkov.dev |
| `electron/updater.mjs` | Обновление по кнопке (GitHub Releases) |
| `src/overlay/`, `src/components/MiniMap.tsx`, `src/lib/hudModel.ts` | Виджет поверх игры, миникарта, расчёт HUD |
| `scripts/sync-data.mjs` | Качает `json.tarkov.dev/{regular,pve}/*`, конфиг карт tarkov-dev и SVG-карты; собирает `public/data/*.json` |
| `src/lib/crs.ts` | Перевод игровых координат в координаты карты (как на tarkov.dev) |
| `src/lib/quests.ts` | Доступность квестов, цели на карте, расчёт снаряжения |
| `src/lib/raids.ts` | Разбиение на рейды и оценка времени |
| `src/lib/route.ts` | Порядок обхода точек |
| `src/lib/navgrid.ts`, `src/lib/pathWorker.ts` | Сетка проходимости из SVG-карты и поиск путей в фоновом потоке |
| `src/lib/realRoutes.ts` | Порядок точек, выход и время рейда по реальным путям |
| `src/lib/navdetail.ts`, `src/lib/detailWorker.ts` | Многоэтажная сетка у цели, пути через двери и лестницы |
| `src/lib/navigator.ts` | Разбор имён скриншотов, слежение за папкой скриншотов |
| `src/lib/gamelogs.ts`, `src/lib/progressSync.ts` | Карта, режим и события квестов из логов; применение прогресса |
| `src/lib/ocr.ts` | Распознавание списка заданий и (бета) инвентаря |
| `src/lib/market.ts` | Цены, комиссия барахолки, рекомендация |
| `src/components/MapView.tsx` | Карта Leaflet: подложка, этажи, метки, маршруты |
| `src/components/Hud.tsx` | HUD навигатора и радар |

Стек: Electron, React 18, TypeScript, Vite, Leaflet, Tesseract.js.
