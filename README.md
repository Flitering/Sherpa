# Sherpa — проводник по квестам Escape from Tarkov

Веб-приложение: отмечаешь активные квесты (свои и тиммейтов), выбираешь карту — и получаешь
точки целей на карте, порядок обхода, список ключей, маркеров и предметов.

## Запуск

```bash
npm install
npm run sync      # скачать свежие данные квестов и карты (повторять после патчей игры)
npm run dev       # http://127.0.0.1:5173
```

`npm run sync -- pve` — обновить только PvE.

## Что умеет

- **Все 13 карт** с этажами и подписями районов (на русском). SVG-схемы лежат локально; для Лаборатории, Лабиринта и Ледокола — тайлы с assets.tarkov.dev.
- **500+ квестов PvP и PvE** на русском: цели, координаты зон, места появления квестовых предметов, ключи, иконки, картинки, вики.
- **Группа**: у каждого игрока свои статусы квестов; общие цели сливаются в одну точку.
- **Рейды по районам**: цели карты автоматически делятся на несколько рейдов, чтобы каждый укладывался в
  реалистичное время (скорость, обходы зданий, время на каждую цель, дорога до выхода; всё настраивается).
  Рейд получает название по районам, ближайший спавн и выход.
- **Реальные пути**: маршрут идёт по улицам и проходам в обход зданий, заборов, воды, скал и минных полей;
  порядок точек и время рейда пересчитываются по настоящей длине пути. В навигаторе стрелка ведёт к ближайшему
  повороту пути. Для Лаборатории, Лабиринта и Ледокола (нет SVG-схемы) — по прямой.
- **Пути внутри зданий**: клик по цели строит подробный маршрут через дверные проёмы и лестницы (сетка 0,25 м
  по этажам SVG-карты), карта сама переключает этаж, на ней отмечены «ВХОД» и «▲ N этаж». Навигатор у цели
  (ближе 140 м) ведёт так же и подсказывает следующее действие.
- **Синхронизация квестов**: из логов игры (notifications.log: взят/выполнен/провален) — автоматически и по всей
  истории; со скриншота списка заданий (распознавание текста Tesseract.js). Квесты-предшественники активных
  отмечаются выполненными.
- **Барахолка**: цены всех предметов (минимальная, средняя за сутки, тренд, лоты, лучший торговец), подсказка при
  наведении на любую иконку, комиссия по формуле игры, рекомендуемая цена с учётом спроса, список «Мой лут».
- **Снаряжение**: ключи, маркеры, предметы для закладки, что найти и что сдать (FIR).
- **Навигатор**: позиция и направление взгляда по скриншотам игры, карта и начало рейда — по логам.
  HUD со стрелкой к следующей цели, дистанцией, подсказкой по этажу, радаром и таймером рейда.
  Может открываться отдельным окном поверх игры (Chrome/Edge, Document Picture-in-Picture).

## Навигатор — как пользоваться

1. Вкладка «Навигатор» → «Выбрать папку» → `ДокументыEscape From TarkovScreenshots`.
2. По желанию — папка `Logs` из папки установки игры: карта будет переключаться сама.
3. «Рейды» → раскрыть рейд → «В рейд — запустить навигатор».
4. В игре нажимать клавишу скриншота (Print Screen) — HUD покажет, куда идти.
5. Игра в режиме «Оконный без рамки» + «Открыть окно навигатора» — HUD поверх игры или на втором мониторе.

Нужен Chrome или Edge (File System Access API). Скриншоты не удаляются — чисти папку сам.

## Устройство

| Файл | Что делает |
|---|---|
| `scripts/sync-data.mjs` | Качает `json.tarkov.dev/{regular,pve}/*`, конфиг карт из репозитория tarkov-dev, SVG-карты; собирает `public/data/*.json` |
| `src/lib/crs.ts` | Перевод игровых координат в координаты карты (как на tarkov.dev) |
| `src/lib/quests.ts` | Доступность квестов, цели на карте, расчёт снаряжения |
| `src/lib/route.ts` | Порядок обхода точек |
| `src/lib/raids.ts` | Разбиение на рейды и оценка времени |
| `src/lib/navgrid.ts` | Сетка проходимости из SVG-карты (здания, заборы, вода, скалы, мины) |
| `src/lib/pathWorker.ts` | Поиск путей (Дейкстра/A*) в фоновом потоке |
| `src/lib/navdetail.ts`, `src/lib/detailWorker.ts` | Подробная многоэтажная сетка у цели и поиск пути через двери/лестницы |
| `src/lib/gamelogs.ts`, `src/lib/progressSync.ts` | События квестов из логов игры и применение прогресса |
| `src/lib/ocr.ts` | Распознавание списка заданий и (бета) инвентаря |
| `src/lib/market.ts` | Цены, комиссия барахолки, рекомендация |
| `src/lib/realRoutes.ts` | Порядок точек, выход и время рейда по реальным путям |
| `src/lib/navigator.ts` | Разбор имён скриншотов, слежение за папками скриншотов и логов |
| `src/components/Hud.tsx` | HUD навигатора и радар |
| `src/components/MapView.tsx` | Карта Leaflet: подложка, этажи, метки |

## Безопасность и блокировки

Приложение **никак не взаимодействует с игрой**: не читает память процесса, не внедряется
в игру, не рисует поверх неё и не трогает её файлы. Оно работает в обычном браузере на публичных
данных tarkov.dev — с точки зрения античита (BattlEye) это то же самое, что открыть вики.

Планы на будущее и их риск:

| Функция | Как работает | Риск |
|---|---|---|
| Синхронизация с TarkovTracker | HTTP-запросы к их API по токену | нет — игры не касается |
| Чтение логов игры (как TarkovMonitor) | читает текстовые логи, которые игра сама пишет на диск | очень низкий; BSG официально не комментировала, TarkovMonitor широко используется |
| «Где я» по скриншоту (**сделано**) | игра пишет координаты в имя файла скриншота, приложение читает имя файла; клавишу нажимает сам игрок | очень низкий — так же работают Tarkov Pilot и TarkovMonitor |
| Карта по логам (**сделано**) | чтение текстовых логов игры | очень низкий |
| Окно поверх игры (**сделано**) | отдельное окно браузера (Picture-in-Picture), в игру не встраивается | нет |
| Синхронизация квестов по логам (**сделано**) | чтение notifications.log | очень низкий — так же делает TarkovMonitor |
| Распознавание скриншотов (**сделано**) | снимок экрана через браузер (с разрешения) или файл скриншота | нет — игра не затрагивается |
| Цена при наведении **внутри игры** | глобальный перехват мыши + чтение экрана (как RatScanner) | в браузере невозможно; нужно отдельное приложение — не делаем |
| Автонажатие клавиши скриншота | эмуляция ввода | **не делаем** — автоматизация ввода может считаться нарушением |
| Оверлей поверх игры | **не делаем** через внедрение в процесс/DirectX; только отдельное окно или второй монитор | внедрение — высокий риск бана |
| Чтение памяти, автоматизация ввода | **никогда** | бан |

Зависимости: React, Leaflet, Vite — версии закреплены, `npm audit` — 0 уязвимостей.
Dev-сервер слушает только `127.0.0.1`.
