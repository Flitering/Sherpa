# Sherpa — проводник по квестам Escape from Tarkov

Sherpa помогает пройти квесты быстрее: показывает, **куда идти, в каком порядке, что взять с собой и за сколько продать лут**.
Отмечаешь активные квесты (свои и тиммейтов) — приложение разбивает цели на рейды, строит реальные маршруты по карте
и ведёт тебя в рейде, как навигатор.

Работает в браузере (Chrome/Edge), данные — с [tarkov.dev](https://tarkov.dev), интерфейс в стиле Таркова.

## Возможности

### 🗺 Карты и квесты
- **Все 13 локаций**: Улицы Таркова, Эпицентр, Таможня, Завод, Ледокол, Развязка, Лаборатория, Лабиринт, Маяк, Резерв,
  Берег, Терминал, Лес — с переключением этажей и подписями районов на русском.
- **500+ квестов PvP и PvE** на русском: цели, зоны на карте, все места появления квестовых предметов, нужные ключи,
  иконки предметов, картинки квестов, ссылки на вики.
- Фильтры «Активные / Доступные / Все»: доступные учитывают уровень и выполненные предыдущие квесты.
- Невзятые квесты карты можно показать серыми точками и взять прямо с карты.

### 🧭 Планирование рейдов
- **Рейды по районам**: цели карты автоматически делятся на несколько рейдов, каждый укладывается в реалистичное время.
  Рейд получает название по районам («Аптека 1 · LexOs»), вероятный спавн и ближайший выход.
- **Реальные пути**: маршрут идёт по улицам и проходам, в обход зданий, заборов, воды, скал и минных полей.
  Порядок точек и время пересчитываются по настоящей длине пути.
- **Пути внутри зданий**: клик по цели строит подробный маршрут через дверные проёмы и лестницы, карта сама
  переключается на нужный этаж, на ней отмечены «ВХОД» и «▲ 2 этаж». Под целью — подсказка:
  «вход в здание → ▲ подняться на 2 этаж → цель».
- Настройки темпа: скорость, какую долю рейда планировать, учитывать ли зоны убийств. Выход можно выбрать вручную.
- Квесты без точек на карте (убийства, выживание) показываются отдельно — «попутно в любом рейде».

### 🎯 Навигатор в рейде
- **Твоя позиция и направление взгляда** по скриншотам игры: нажал Print Screen — увидел себя на карте.
- **HUD**: стрелка к следующей цели, дистанция по пути, подсказка «▲ наверх: 2 этаж · через 12 м», «выше на 2 эт.»,
  мини-радар, таймер рейда и отставание от плана, кнопки «Выполнено / Пропустить».
- У цели навигатор ведёт через двери и лестницы, а не напрямик сквозь стены.
- **Окно поверх игры** (Picture-in-Picture) — для режима «Оконный без рамки» или второго монитора.
- **Карта и PvP/PvE определяются сами** по логам игры, начало рейда засекается автоматически.

### ✅ Прогресс квестов
- **Из логов игры**: «задание получено / выполнено / провалено» отмечается автоматически; кнопка «Загрузить прогресс
  из всех логов» восстанавливает всю историю.
- **Со скриншота списка заданий**: распознавание текста находит активные квесты; все квесты, без которых они бы
  не открылись, отмечаются выполненными.
- Ручные отметки: статус квеста у каждого игрока и галочки по отдельным целям.
- Сохранение прогресса в файл и загрузка из файла.

### 👥 Группа
- Игроки «Игрок 1, Игрок 2, Игрок 3…» — добавляй, переименовывай, задавай цвет и уровень.
- Общие цели нескольких игроков сливаются в одну точку маршрута и помечаются на карте.
- Отметка «это я» — к этому игроку применяются логи и скриншоты с твоего компьютера.

### 💰 Барахолка и снаряжение
- **Что взять в рейд**: ключи, маркеры, предметы для закладки; что найти на карте; что сдать торговцам (с пометкой FIR).
- **Цена при наведении** на любую иконку предмета: минимальная на барахолке, средняя за сутки, тренд за 48 ч,
  число лотов, лучший торговец, цена за клетку.
- **Рекомендуемая цена продажи** с учётом спроса и комиссии барахолки по формуле игры; если выгоднее торговец — скажет.
  Учитывается скидка разведцентра 3 уровня.
- **Мой лут**: список предметов с итоговой стоимостью, сортировка по цене за клетку; распознавание инвентаря
  со скриншота (бета).
- Обновление цен с tarkov.dev одной кнопкой.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) 20+ и браузер Chrome или Edge.

```bash
npm install
npm run sync      # скачать квесты, цены и карты (повторять после патчей игры)
npm run dev       # открыть http://127.0.0.1:5173
```

`npm run sync -- pve` — обновить только PvE.

## Как пользоваться

1. **Группа** — назови игроков, укажи уровни, отметь «это я».
2. **Квесты** — отметь взятые квесты (кружок игрока: не взят → активен → выполнен) или распознай их со скриншота.
3. **Рейды** — выбери карту сверху, раскрой рейд, кликай по целям, чтобы увидеть подробный путь.
4. **Снаряжение** — собери ключи и предметы.
5. **Навигатор** — один раз выбери папки:
   - скриншоты: `Документы\Escape From Tarkov\Screenshots`;
   - логи (по желанию): `Logs` в папке установки игры, например `C:\Battlestate Games\Escape from Tarkov\Logs`.
6. **Рейды → «В рейд — запустить навигатор»**, в игре нажимай Print Screen — HUD покажет, куда идти.
   Для HUD поверх игры: режим «Оконный без рамки» и кнопка «Открыть окно навигатора».

Скриншоты приложение не удаляет — чисти папку сам.

## Безопасность и блокировки

Приложение **не взаимодействует с процессом игры**: не читает память, не внедряется в игру, не рисует поверх неё,
не нажимает клавиши и не изменяет файлы. Оно работает в обычном браузере и только читает то, что игра сама пишет на диск.

| Функция | Как работает | Риск |
|---|---|---|
| Данные квестов, карт, цен | публичные данные tarkov.dev | нет |
| Позиция по скриншоту | игра пишет координаты в имя файла скриншота, приложение читает имя; клавишу нажимает сам игрок | очень низкий — так же работают Tarkov Pilot и TarkovMonitor |
| Карта, режим, квесты по логам | чтение текстовых логов игры | очень низкий — так же делает TarkovMonitor |
| Распознавание скриншотов | снимок экрана через браузер (с твоего разрешения) или файл | нет |
| Окно навигатора поверх игры | отдельное окно браузера, в игру не встраивается | нет |

**Чего приложение не делает и делать не будет**: чтение памяти игры, внедрение в процесс или DirectX-оверлей,
эмуляция ввода (в том числе автонажатие клавиши скриншота). Цену при наведении **внутри игры** браузер показать не может —
для этого нужен перехват мыши и экрана отдельной программой.

Зависимости закреплены по версиям, `npm audit` — 0 уязвимостей. Dev-сервер слушает только `127.0.0.1`.

## Устройство

| Файл | Что делает |
|---|---|
| `scripts/sync-data.mjs` | Качает `json.tarkov.dev/{regular,pve}/*`, конфиг карт tarkov-dev и SVG-карты; собирает `public/data/*.json` |
| `src/lib/crs.ts` | Перевод игровых координат в координаты карты (как на tarkov.dev) |
| `src/lib/quests.ts` | Доступность квестов, цели на карте, расчёт снаряжения |
| `src/lib/raids.ts` | Разбиение на рейды и оценка времени |
| `src/lib/route.ts` | Порядок обхода точек |
| `src/lib/navgrid.ts`, `src/lib/pathWorker.ts` | Сетка проходимости из SVG-карты и поиск путей в фоновом потоке |
| `src/lib/realRoutes.ts` | Порядок точек, выход и время рейда по реальным путям |
| `src/lib/navdetail.ts`, `src/lib/detailWorker.ts` | Многоэтажная сетка у цели, пути через двери и лестницы |
| `src/lib/navigator.ts` | Разбор имён скриншотов, слежение за папкой скриншотов |
| `src/lib/gamelogs.ts`, `src/lib/progressSync.ts` | Карта, режим и события квестов из логов; применение прогресса |
| `src/lib/ocr.ts` | Распознавание списка заданий и (бета) инвентаря |
| `src/lib/market.ts` | Цены, комиссия барахолки, рекомендация |
| `src/components/MapView.tsx` | Карта Leaflet: подложка, этажи, метки, маршруты |
| `src/components/Hud.tsx` | HUD навигатора и радар |

Стек: React 18, TypeScript, Vite, Leaflet, Tesseract.js.
