# Безопасность

Нашёл уязвимость в Sherpa — пожалуйста, не публикуй её в открытом Issue. Сообщи через
[приватное сообщение об уязвимости](https://github.com/Flitering/Sherpa/security/advisories/new) на GitHub.

## Как устроена защита приложения

- Окна показывают только интерфейс Sherpa: переход на другие адреса и новые окна запрещены, внешние ссылки
  открываются в браузере и только для известных сайтов.
- Content-Security-Policy: скрипты только из приложения, сеть — только к tarkov.dev.
- Интерфейс изолирован от системы (contextIsolation, sandbox); мост к основному процессу проверяет, из какого окна
  пришёл запрос и что в нём (виджет и карточка цены не могут читать файлы или ставить обновления).
- Чтение файлов — только внутри папок скриншотов и логов игры (с учётом символических ссылок).
- Распознаватель текста и словари входят в приложение — никакого кода из сети во время работы.
- В собранном приложении отключены запуск как Node, отладочные флаги и переменные окружения разработки
  (Electron fuses), проверяется целостность архива приложения.
- Обновления скачиваются только с GitHub Releases этого репозитория и сверяются по SHA-512.

Приложение не взаимодействует с процессом игры: не читает память, не внедряется, не нажимает клавиши.
